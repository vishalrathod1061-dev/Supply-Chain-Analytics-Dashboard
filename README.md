# Supply Chain Analytics Dashboard

## Project Overview

This project analyzes supply chain operations to understand order performance, revenue, profitability, inventory, and delivery efficiency.

## Tools Used

* Microsoft Power BI
* SQL
* MySQL
* Power Query
* DAX

## Key Performance Indicators (KPIs)

* Total Orders
* Total Revenue
* Total Profit
* Total Products
* On-Time Delivery Percentage
* Average Delivery Days
* Inventory Value

## Key Features

* Order and sales analysis
* Product performance analysis
* Warehouse analysis
* Inventory monitoring
* Shipment and delivery analysis

## Project File

The Power BI dashboard is available in this repository as a `.pbix` file.

## Objective

To identify operational trends and provide data-driven insights for improving supply chain efficiency.
